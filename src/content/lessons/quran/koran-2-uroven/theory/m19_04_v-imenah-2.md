# Соединительная хамза в именах (2): семь слов

Аль-Джазари перечислил **семь** имён (мufrad) с хамзой васль: «**وَفِي ابْنٍ مَعَ ابْنَتْ، امْرِئٍ، وَاثْنَيْنِ، وَامْرَأَةٍ، وَاسْمٍ مَعَ اثْنَتَيْنِ**». Во всех хамза васль — **кясра** (начинают проверочно).

## Семь слов

1. **ابْن**: «عِيسَى ابْنُ مَرْيَمَ» (аль-Бакара, 87) → начать «ابْنُ مَرْيَمَ»;
2. **ابْنَت**: «وَمَرْيَمَ ابْنَتَ عِمْرَانَ» (ат-Тахрим) → «ابْنَتْ» (кясра хамзы + «та мабсута» по расму);
3. **امْرِئ**: «لِكُلِّ امْرِئٍ مِنْهُمْ مَا اكْتَسَبَ» (ан-Нур, 11) → «امْرِئٍ»;
4. **اثْنَيْن**: «مِنَ الضَّأْنِ اثْنَيْنِ» → «اثْنَيْنِ»;
5. **امْرَأَة**: «وَإِنِ امْرَأَةٌ خَافَتْ» → «امْرَأَة»;
6. **اسْم**: «وَاذْكُرِ اسْمَ اللَّهِ» → «اسْمُ اللَّهِ»;
7. **اثْنَتَيْن**: «فَإِنْ كَانَتَا اثْنَتَيْنِ» (ан-Ниса, 176) → «اثْنَتَيْنِ».

## Диковинка слова «امْرِئ»

В «امْرِئ» огласовка **предпоследней** буквы («ра») меняется вслед за огласовкой **последней** (хамзы — носителя и'раба):

- рафъ: «امْرُؤٌ» («ра» с даммой);
- насб: «امْرَأً» («ра» с фатхой);
- джарр: «امْرِئٍ» («ра» с кясрой).

Примеры: «مَا كَانَ أَبُوكِ امْرَأَ سَوْءٍ»، «إِنِ امْرُؤٌ هَلَكَ» → «امْرُؤ»، «لِكُلِّ امْرِئٍ» → «امْرِئ». (Аналога этому в арабском почти нет.)
