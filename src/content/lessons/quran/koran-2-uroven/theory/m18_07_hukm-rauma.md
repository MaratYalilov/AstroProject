# Хукм раума — как при соединении

Важное правило: **хукм раума — как хукм соединения (васль)**. То есть слово, на котором делаешь раум, обрабатывается так, **как если бы ты его соединял** с последующим.

## 1. Мадд — как при васле (нет арид ли-сукун)

Если перед последней буквой — буква мадда, при рауме она тянется **на 2 харакята** (как при васле), а **не** как арид ли-сукун (2/4/6):

- «<span class="arab">وَإِيَّاكَ نَسۡتَعِينُ</span>» — при васле «<span class="arab">نَسْتَعِينُ</span>» (естественный мадд, 2). При **рауме** — «<span class="arab">نَسْتَعِينُ</span>» с **тихой (пониженной) даммой**: всё те же **2 харакята**, а не 4/6 (арид ли-сукун здесь не работает).

## 2. Тафхим/таркик «ра» — как при васле

Букву (особенно **«ра»**) при рауме огрубляют/смягчают так же, как **при соединении**:

- «<span class="arab">فَيَغۡفِرُ لِمَن يَشَآءُ</span>» — при васле «ра» с **даммой → тафхим**. При **рауме**: «<span class="arab">فَيَغْفِرُ</span>» с **тихой даммой** — «ра» **тафхим**. А при **чистом сукуне** — «<span class="arab">فَيَغْفِرْ</span>»: «ра» неподвижная после кясры → **таркик** (другое!).
- «<span class="arab">فِي لَيۡلَةِ ٱلۡقَدۡرِ</span>» — при васле «ра» с **кясрой → таркик**. При **рауме**: «<span class="arab">الْقَدْرِ</span>» с **тихой кясрой** — **таркик**. А при **чистом сукуне** — «<span class="arab">الْقَدْرْ</span>»: «ра» неподвижная после сукуна с фатхой перед → **тафхим**.

## Вывод

При рауме смотрим на состояние буквы **в соединении**: была там тафхим — и при рауме тафхим; была таркик — и при рауме таркик; мадд — как при васле (2 харакята). Это и значит «хукм раума — хукм васля».

| Пример | Правило | Твёрдость/мягкость |
|---|---|---|
| <span class="arab">فَيَغْفِرُ</span> | слитное чтение (васль) | **твёрдая** (тафхим) |
| <span class="arab">فَيَغْفِرُ</span> | остановка с раумом — **тихая дамма** | **твёрдая** (тафхим) |
| <span class="arab">فَيَغْفِرْ</span> | остановка с сукуном | **мягкая** (таркик) |
| <span class="arab">لَيْلَةِ الْقَدْرِ</span> | слитное чтение (васль) | **мягкая** (таркик) |
| <span class="arab">لَيْلَةِ الْقَدْرِ</span> | остановка с раумом — **тихая кясра** | **мягкая** (таркик) |
| <span class="arab">لَيْلَةِ الْقَدْرْ</span> | остановка с сукуном | **твёрдая** (тафхим) |
