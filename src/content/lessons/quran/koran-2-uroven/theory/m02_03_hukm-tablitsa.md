# Хукм таджвида (уточнение)

Уточнение срединной позиции: нужно различать **уровни** таджвида.

## Что обязательно (под угрозой греха)

**Обязательно** — избегать **явной ошибки (ляхн джали)**: то есть произносить буквы с их **верными махраджами и свойствами** так, чтобы **не искажались смысл и грамматика**. Замена одной буквы другой или изменение огласовки, меняющее смысл (как أَنْعَمْتَ → أَنْعَمْتُ), — **запретны**. Этот уровень — обязанность каждого читающего Коран.

## Что относится к совершенству (желательно)

**Тонкие** правила «украшения» чтения — точные **степени мадда**, оттенки гунны, мера свойств — относятся к **совершенству (إتقان)**. Их **упущение** для **простого мусульманина** не является **грехом** (это **ляхн хафи** — скрытая ошибка), хотя в обстановке **обучения и устной передачи** их избегать необходимо.

## Итог

Бейт «من لم يجوّد القرآن آثم» понимается так: грех — за **явную** ошибку (искажение смысла/грамматики), а не за каждый недостающий «тонкий» нюанс. Это и есть **срединный** подход: ни запугивание, ни попустительство.

## Схема: уровни свойств букв

![Классификация свойств букв по степени обязательности их соблюдения](/media/quran/koran-2-uroven/img/m02/svoystva_bukv_klassifikatsiya.png)
*Свойства, изменение которых выводит букву за её границы (места образования) — их соблюдение ваджиб, нарушение бесспорно харам. Украшающие, утончающие свойства различаются по обстановке: при простом чтении — для незнающего правил извинительно, для знающего — порицаемо; при обучении и устной передаче — соблюдение ваджиб, а нарушение харам, так как это ложь при передаче.*
