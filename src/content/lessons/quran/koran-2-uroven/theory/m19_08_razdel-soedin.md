# Хамза васль на хамзу катъ (неподвижную)

Если **хамза васль** (та, что выпадает при соединении) входит на **хамзу катъ с сукуном**, при **начале** вторую (неподвижную катъ) **заменяют буквой мадда, однородной огласовке хамзы васль**.

## Примеры

- **<span class="arab">ائْتُونِي</span>** (хамза васль — кясра по правилу глагола? нет — здесь третья буква мнимо с даммой → кясра; но при наличии вав множества — см. ниже): «<span class="arab">فِي السَّمَاوَاتِ ائْتُونِي بِكِتَابٍ</span>» — начать «<span class="arab">اِيتُونِي</span>» (вторая хамза → «йа» по кясре первой);
- **<span class="arab">اؤْتُمِنَ</span>**: «<span class="arab">فَلْيُؤَدِّ الَّذِي اؤْتُمِنَ أَمَانَتَهُ</span>» — хамза васль с **даммой** (третья буква «та» с даммой по правилу глагола), вторая хамза → «вав»: начать **<span class="arab">اُوتُمِنَ</span>**;
- **<span class="arab">ائْذَنْ</span>**: «<span class="arab">وَمِنْهُمْ مَنْ يَقُولُ ائْذَنْ لِي</span>» — начать «<span class="arab">اِيذَنْ</span>» (вторая хамза → «йа»);
- «<span class="arab">لَا يَرْجُونَ لِقَاءَنَا ائْتِ بِقُرْآنٍ</span>» — начать «<span class="arab">اِيتِ</span>».

## Итог

Хамза васль + хамза катъ-сукун → при начале вторая хамза становится **буквой мадда** под огласовку хамзы васль (<span class="arab">د</span>амма→вав, кясра→йа). Всё это — **проверочное** начало (намеренно не начинают: оно не «тамм» и не «кафи»).
