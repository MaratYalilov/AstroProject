# Хамза васль на хамзу катъ (неподвижную)

Если **хамза васль** (та, что выпадает при соединении) входит на **хамзу катъ с сукуном**, при **начале** вторую (неподвижную катъ) **заменяют буквой мадда, однородной огласовке хамзы васль**.

## Примеры

- **ائْتُونِي** (хамза васль — кясра по правилу глагола? нет — здесь третья буква мнимо с даммой → кясра; но при наличии вав множества — см. ниже): «فِي السَّمَاوَاتِ ائْتُونِي بِكِتَابٍ» — начать «اِيتُونِي» (вторая хамза → «йа» по кясре первой);
- **اؤْتُمِنَ**: «فَلْيُؤَدِّ الَّذِي اؤْتُمِنَ أَمَانَتَهُ» — хамза васль с **даммой** (третья буква «та» с даммой по правилу глагола), вторая хамза → «вав»: начать **اُوتُمِنَ**;
- **ائْذَنْ**: «وَمِنْهُمْ مَنْ يَقُولُ ائْذَنْ لِي» — начать «اِيذَنْ» (вторая хамза → «йа»);
- «لَا يَرْجُونَ لِقَاءَنَا ائْتِ بِقُرْآنٍ» — начать «اِيتِ».

## Итог

Хамза васль + хамза катъ-сукун → при начале вторая хамза становится **буквой мадда** под огласовку хамзы васль (دамма→вав, кясра→йа). Всё это — **проверочное** начало (намеренно не начинают: оно не «тамм» и не «кафи»).
