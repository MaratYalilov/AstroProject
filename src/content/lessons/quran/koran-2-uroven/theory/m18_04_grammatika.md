# Бина и и'раб (почему «<span class="arab">إِلَّا بِفَتْحٍ أَوْ بِنَصْبٍ</span>»)

## Шесть названий для трёх огласовок

У последней буквы слова огласовка бывает либо **и'рабной** (меняется по месту в предложении), либо **бинной** (неизменной). Отсюда **два** названия у каждой из трёх огласовок:

| звук | бина (неизменна) | и'раб (изменчива) |
|---|---|---|
| **фатха** | <span class="arab">فتح</span> (<span class="arab">مفتوح</span>) | <span class="arab">نصب</span> (<span class="arab">منصوب</span>) |
| **дамма** | <span class="arab">ضم</span> (<span class="arab">مضموم</span>) | <span class="arab">رفع</span> (<span class="arab">مرفوع</span>) |
| **кясра** | <span class="arab">كسر</span> (<span class="arab">مكسور</span>) | <span class="arab">جر</span> (<span class="arab">مجرور</span>) |

Пример бины: «<span class="arab">هَؤُلَاءِ</span>» всегда с кясрой (<span class="arab">مبني على الكسر</span>), где бы ни стояло. Пример и'раба: <span class="arab">لفظ الجلا</span>ля — то <span class="arab">رفع</span>, то насб, то джарр.

## Смысл слов аль-Джазари

«<span class="arab">إِلَّا إِذَا رُمْتَ فَبَعْضُ الحَرَكَهْ،</span> **<span class="arab">إِلَّا بِفَتْحٍ أَوْ بِنَصْبٍ</span>**»:

- **раум** возможен на **дамме** (фатх/рафъ — нет... т.е. на <span class="arab">ضم</span>/<span class="arab">رفع</span>) и **кясре** (<span class="arab">كسر</span>/<span class="arab">جر</span>) — это **четыре** из шести «названий»;
- **исключаются <span class="arab">فتح</span> и <span class="arab">نصب</span>** (то есть **фатха** в обоих её видах — бинная «фатх» и и'рабная «насб»): на фатхе раума **нет**.

То есть «<span class="arab">اياك</span>» (фатха) при остановке — только **сукун**: «<span class="arab">إِيَّاكْ</span>», нельзя «<span class="arab">إِيَّاكَ</span>» с частью фатхи (чтецы этого **не передали**, хотя в книгах языка об этом расширяются).

## Ишмам — только дамма

«<span class="arab">وَأَشِمْ إِشَارَةً بِالضَّمِّ فِي رَفْعٍ وَضَمْ</span>» — ишмам (губное указание) только когда буква **с даммой**, будь та бинной (**<span class="arab">ضم</span>**) или и'рабной (**<span class="arab">رفع</span>**).
