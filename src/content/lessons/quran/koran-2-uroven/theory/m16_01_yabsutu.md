# «<span class="arab">يبصُط</span>» и её «сёстры» (буква <span class="arab">ص</span> ↔ <span class="arab">س</span>)

В арабском есть глаголы **<span class="arab">بَسَط</span>** и **<span class="arab">سَيْطَر</span>**. Часть племён **огрубляла «син» до «сад»** (под влиянием соседней «<span class="arab">طا</span>» — буквы исти'ля/итбак): «<span class="arab">بَصَط</span>»<span class="arab">،</span> «<span class="arab">صَيْطَر</span>». По их диалекту **четыре** слова записаны в мусхафе через **«сад»**. Переданы оба чтения (через «син» — по основе; через «сад» — по расму и диалекту). У Хафса по аш-Шатыбийи:

## Четыре слова

1. **<span class="arab">وَيَبْسُطُ</span>** (аль-Бакара, 245): «<span class="arab">وَاللَّهُ يَقْبِضُ وَيَبْسُطُ</span>» — Хафс читает **только «син»**. Знак: **маленькая «син» НАД «сад»** (= читай через «син»);
2. **<span class="arab">بَسْطَةً</span>** (аль-А'раф, 69): «<span class="arab">وَزَادَكُمْ فِي الْخَلْقِ بَسْطَةً</span>» — **только «син»**, «син» сверху;
3. **<span class="arab">الْمُصَيْطِرُونَ</span>** (ат-Тур, 37): «<span class="arab">أَمۡ هُمُ ٱلۡمُصَيۡطِرُونَ</span>» — **«сад» И «син»** (с «сад» известнее). Знак: **«син» ПОД «сад»** (= оба варианта);
4. **<span class="arab">بِمُصَيْطِرٍ</span>** (аль-Гашия, 22): «<span class="arab">لَّسۡتَ عَلَيۡهِم بِمُصَيۡطِرٍ</span>» — **только «сад»**, поэтому никакой маленькой «син» нет (ни сверху, ни снизу).

## Правило знака

- **«син» сверху** «сад» → читай **только через «син»** (<span class="arab">يبسط، بسطة</span>);
- **«син» снизу** «сад» → читай **двумя** способами (<span class="arab">المصيطرون</span>);
- **нет «син»** → читай как написано, через **«сад»** (<span class="arab">بمصيطر</span>).

(По путям «Тайибат ан-Нашр» у этих слов есть и другие варианты; здесь — путь аш-Шатыбийи.)
