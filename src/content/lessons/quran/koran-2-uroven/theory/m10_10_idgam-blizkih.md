# Идгам близких букв (мутакарибайн)

**Близкие буквы (<span class="arab">متقاربان</span>)** — близкие **по махраджу** (и по свойствам). Условие идгама прежнее: **первая неподвижна**.

## Примеры

- **<span class="arab">ق</span> → <span class="arab">ك</span>**: **<span class="arab">أَلَمۡ نَخۡلُقكُّم</span>** (аль-Мурсалят) — «каф» из задней части языка, «кяф» чуть ближе; «каф» неподвижна перед «кяф» → по Хафсу **полный идгам** (удвоённая «кяф»); {Quran}77:20{/Quran}
- **<span class="arab">ت</span> → <span class="arab">ث</span>**: **<span class="arab">كَذَّبَتۡ ثَمُودُ</span>** — «та» (кончик языка у резцов) близка к «са» (дёсенная). Здесь часть передаёт **изхар**, часть — **идгам**.

## Идгам по согласию и по расхождению

Среди близких букв:

- **одни** сливаются **по согласию** (например, <span class="arab">ق</span> в <span class="arab">ك</span> в <span class="arab">نَخْلُقكُّمْ</span> по Хафсу) — это разбирается в таджвиде;
- **другие** — **по расхождению** между чтецами (как <span class="arab">كَذَّبَتۡ ثَمُودُ</span>) — это уже относится к **науке кираатов**, а не таджвида.

Также к близким относят идгам **«нун» с сукуном** в <span class="arab">ل، ر</span> (разбирается в главе о «нун» с сукуном) и **«лям» определённого артикля** в «солнечные» буквы (отдельный урок).
