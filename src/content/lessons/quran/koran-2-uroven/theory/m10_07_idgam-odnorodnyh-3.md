# Идгам однородных (часть 3): <span class="arab">ث</span> → <span class="arab">ذ</span>

**Случай 6: идгам «са» в «заль».**

## Пример

Один-единственный в Коране — **<span class="arab">يَلْهَث ذَّٰلِكَ</span>** (аль-А'раф: <span class="arab">مَثَلُ الْقَوْمِ</span>... <span class="arab">كَمَثَلِ الْكَلْبِ إِن تَحْمِلْ عَلَيْهِ يَلْهَثْ أَوْ تَتْرُكْهُ يَلْهَث ذَّٰلِكَ</span>).

«<span class="arab">ثَاء</span> (ҫә)» и «<span class="arab">ذَال</span> (ҙәль)» — буквы **одного махраджа** («дёсенные», лисавийя). Здесь «са» неподвижна перед «заль»:

- при **соединении** «са» **превращают** в «заль» и сливают → удвоённая **<span class="arab">ذ</span>**: «<span class="arab">يَلْهَذّٰلِكَ</span>».
- при **остановке** на <span class="arab">يَلْهَثْ</span> — произносится «са» (<span class="arab">ث</span>).

*(По другому достоверному пути передано и чтение с **изхаром** — «<span class="arab">يَلْهَثْ ذَٰلِكَ</span>»; это вопрос кираатов. По распространённой передаче Хафса — идгам.)*
