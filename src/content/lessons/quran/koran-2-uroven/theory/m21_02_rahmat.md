# «رحمت» (7 мест)

Аль-Джазари (бейт 94): «**وَرَحْمَتِ الزُّخْرُفِ بِالتَّا زَبَرَهْ ∗∗∗ لِلْأَعْرَافِ رُومِ هُودَ كَافِ الْبَقَرَهْ**».

«زَبَرَهْ» = «записали её» (от «зубур» — писание; так Дауду дан «الزَّبُور»); подразумеваемое подлежащее — сподвижники, записавшие Откровение при Пророке ﷺ с его одобрения.

## Семь мест с «та мабсута»

«رَحْمَتُ» (в идафе к явному имени) написано развёрнутой «та» в **семи** местах:

1–2. **аз-Зухруф (32)** — дважды: «أَهُمْ يَقْسِمُونَ رَحْمَتَ رَبِّكَ» и «وَرَحْمَتُ رَبِّكَ خَيْرٌ مِمَّا يَجْمَعُونَ»;
3. **аль-А'раф (56)**: «إِنَّ رَحْمَتَ اللَّهِ قَرِيبٌ مِنَ الْمُحْسِنِينَ»;
4. **ар-Рум (50)**: «فَانْظُرْ إِلَى آثَارِ رَحْمَتِ اللَّهِ»;
5. **Худ (73)**: «رَحْمَتُ اللَّهِ وَبَرَكَاتُهُ عَلَيْكُمْ أَهْلَ الْبَيْتِ»;
6. **«كَافِ» = Марьям (2)**: «ذِكْرُ رَحْمَتِ رَبِّكَ عَبْدَهُ زَكَرِيَّا»;
7. **аль-Бакара (218)**: «أُولَئِكَ يَرْجُونَ رَحْمَتَ اللَّهِ».

При вынужденной/проверочной остановке — с «та»: «رَحْمَتْ».

В остальном Коране «رحمة» — с «та марбута» (ة).
