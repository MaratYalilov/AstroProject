# Правило Хафса (4): удалённый вав

Слова, где конечный **вав** опущен в начертании (выпадает при васле из-за стечения двух сукунов). При вынужденной/проверочной остановке Хафс останавливается **как в расме** — без вава.

## Примеры

- **<span class="arab">وَيَدْعُ الْإِنْسَانُ</span>** (основа «<span class="arab">يَدْعُو</span>», глагол в раф') → остановка «<span class="arab">وَيَدْعْ</span>»;
- **<span class="arab">وَيَمْحُ اللَّهُ</span>** (сура «аш-Шура», основа «<span class="arab">يَمْحُو</span>») → «<span class="arab">وَيَمْحْ</span>»;
- **<span class="arab">يَوْمَ يَدْعُ الدَّاعِ</span>** (основа «<span class="arab">يَدْعُو</span>») → «<span class="arab">يَدْعْ</span>»;
- **<span class="arab">سَنَدْعُ الزَّبَانِيَةَ</span>** (сура «аль-Аляк», основа «<span class="arab">سَنَدْعُو</span>») → «<span class="arab">سَنَدْعْ</span>».

## <span class="arab">وَصَالِحُ الْمُؤْمِنِينَ</span> (сура «ат-Тахрим»)

«<span class="arab">فَإِنَّ اللَّهَ هُوَ مَوْلَاهُ وَجِبْرِيلُ وَصَالِحُ الْمُؤْمِنِينَ</span>» — большинство учёных: основа «<span class="arab">وَصَالِحُو الْمُؤْمِنِينَ</span>» (это **«вав» множества**: «<span class="arab">صَالِحُونَ</span>» → при идафе «<span class="arab">ن</span>ун» отпадает → «<span class="arab">صَالِحُو</span>», затем «вав» опущен из-за стечения сукунов). При остановке: «<span class="arab">وَصَالِحْ</span>» (без вава).

По этому (предпочтительному) мнению при чтении следует **слегка выделить (набр)** слово, давая слушателю понять, что здесь опущена «вав» множества: «<span class="arab">وَجِبْرِيلُ وَصَالِحُ الْمُؤْمِنِينَ</span>». Вав при остановке **не возвращают**.
