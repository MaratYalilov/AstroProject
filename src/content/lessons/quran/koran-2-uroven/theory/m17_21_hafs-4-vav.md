# Правило Хафса (4): удалённый вав

Слова, где конечный **вав** опущен в начертании (выпадает при васле из-за стечения двух сукунов). При вынужденной/проверочной остановке Хафс останавливается **как в расме** — без вава.

## Примеры

- **وَيَدْعُ الْإِنْسَانُ** (основа «يَدْعُو», глагол в раф') → остановка «وَيَدْعْ»;
- **وَيَمْحُ اللَّهُ** (сура «аш-Шура», основа «يَمْحُو») → «وَيَمْحْ»;
- **يَوْمَ يَدْعُ الدَّاعِ** (основа «يَدْعُو») → «يَدْعْ»;
- **سَنَدْعُ الزَّبَانِيَةَ** (сура «аль-Аляк», основа «سَنَدْعُو») → «سَنَدْعْ».

## وَصَالِحُ الْمُؤْمِنِينَ (сура «ат-Тахрим»)

«فَإِنَّ اللَّهَ هُوَ مَوْلَاهُ وَجِبْرِيلُ وَصَالِحُ الْمُؤْمِنِينَ» — большинство учёных: основа «وَصَالِحُو الْمُؤْمِنِينَ» (это **«вав» множества**: «صَالِحُونَ» → при идафе «نун» отпадает → «صَالِحُو», затем «вав» опущен из-за стечения сукунов). При остановке: «وَصَالِحْ» (без вава).

По этому (предпочтительному) мнению при чтении следует **слегка выделить (набр)** слово, давая слушателю понять, что здесь опущена «вав» множества: «وَجِبْرِيلُ وَصَالِحُ الْمُؤْمِنِينَ». Вав при остановке **не возвращают**.
