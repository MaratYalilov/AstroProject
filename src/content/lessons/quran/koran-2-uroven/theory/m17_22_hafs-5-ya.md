# Правило Хафса (5): удалённая йа

Слова, где конечная **йа** опущена в начертании (выпадает при васле из-за стечения двух сукунов). При вынужденной/проверочной остановке Хафс останавливается **как в расме** — без йа.

## Примеры

- **<span class="arab">وَمَا أَنْتَ بِهَادِ الْعُمْيِ</span>** (основа «<span class="arab">بِهَادِي</span>», <span class="arab">و</span>з<span class="arab">ن</span> «фā'иль») → «<span class="arab">بِهَادْ</span>»;
- **<span class="arab">إِنْ يُرِدْنِ الرَّحْمَنُ</span>** (основа «<span class="arab">يُرِيدُنِي</span>») → «<span class="arab">يُرِدْنْ</span>»;
- **<span class="arab">مَنْ هُوَ صَالِ الْجَحِيمِ</span>** (сура «ас-Саффат», основа «<span class="arab">صَالِي</span>») → «<span class="arab">صَالْ</span>»;
- **<span class="arab">فَمَا تُغْنِ النُّذُرُ</span>** (основа «<span class="arab">تُغْنِي</span>») → «<span class="arab">تُغْنْ</span>»;
- **<span class="arab">وَلَهُ الْجَوَارِ الْمُنْشَآتُ</span>** (основа «<span class="arab">الْجَوَارِي</span>»; «ра» — **с тафхимом**) → «<span class="arab">الْجَوَارْ</span>»;
- **<span class="arab">وَسَوْفَ يُؤْتِ اللَّهُ</span>** (основа «<span class="arab">يُؤْتِي</span>») → «<span class="arab">يُؤْتْ</span>» (тяжеловато: стечение двух сукунов);
- **<span class="arab">يُنَجِّي الْمُؤْمِنِينَ</span>** (сура «Юнус», 103) → «<span class="arab">نُنْجْ</span>»;
- **<span class="arab">بِالْوَادِ الْمُقَدَّسِ</span>**<span class="arab">،</span> **<span class="arab">وَادِ النَّمْلِ</span>**<span class="arab">،</span> **<span class="arab">شَاطِئِ الْوَادِي</span>** → «<span class="arab">بِالْوَادْ</span>»<span class="arab">،</span> «<span class="arab">وَادْ</span>»<span class="arab">،</span> «<span class="arab">الْوَادْ</span>»;
- **<span class="arab">يَوْمَ يُنَادِ الْمُنَادِ</span>** → «<span class="arab">يُنَادْ</span>»;
- **<span class="arab">لَهَادِ الَّذِينَ آمَنُوا</span>** → «<span class="arab">لَهَادْ</span>».

## Случай дозволенной остановки

**<span class="arab">وَاخْشَوْنِ الْيَوْمَ أَكْمَلْتُ لَكُمْ دِينَكُمْ</span>** (сура «аль-Маида») — здесь остановка **дозволена** (не только вынужденная): «<span class="arab">فَلَا تَخْشَوْهُمْ وَاخْشَوْنِ</span>» → останавливаются «<span class="arab">وَاخْشَوْنْ</span>» (без йа, как в расме).
