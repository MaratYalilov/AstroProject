# Правило Хафса (5): удалённая йа

Слова, где конечная **йа** опущена в начертании (выпадает при васле из-за стечения двух сукунов). При вынужденной/проверочной остановке Хафс останавливается **как в расме** — без йа.

## Примеры

- **وَمَا أَنْتَ بِهَادِ الْعُمْيِ** (основа «بِهَادِي», وзن «фā'иль») → «بِهَادْ»;
- **إِنْ يُرِدْنِ الرَّحْمَنُ** (основа «يُرِيدُنِي») → «يُرِدْنْ»;
- **مَنْ هُوَ صَالِ الْجَحِيمِ** (сура «ас-Саффат», основа «صَالِي») → «صَالْ»;
- **فَمَا تُغْنِ النُّذُرُ** (основа «تُغْنِي») → «تُغْنْ»;
- **وَلَهُ الْجَوَارِ الْمُنْشَآتُ** (основа «الْجَوَارِي»; «ра» — **с тафхимом**) → «الْجَوَارْ»;
- **وَسَوْفَ يُؤْتِ اللَّهُ** (основа «يُؤْتِي») → «يُؤْتْ» (тяжеловато: стечение двух сукунов);
- **يُنَجِّي الْمُؤْمِنِينَ** (сура «Юнус», 103) → «نُنْجْ»;
- **بِالْوَادِ الْمُقَدَّسِ**، **وَادِ النَّمْلِ**، **شَاطِئِ الْوَادِي** → «بِالْوَادْ»، «وَادْ»، «الْوَادْ»;
- **يَوْمَ يُنَادِ الْمُنَادِ** → «يُنَادْ»;
- **لَهَادِ الَّذِينَ آمَنُوا** → «لَهَادْ».

## Случай дозволенной остановки

**وَاخْشَوْنِ الْيَوْمَ أَكْمَلْتُ لَكُمْ دِينَكُمْ** (сура «аль-Маида») — здесь остановка **дозволена** (не только вынужденная): «فَلَا تَخْشَوْهُمْ وَاخْشَوْنِ» → останавливаются «وَاخْشَوْنْ» (без йа, как в расме).
