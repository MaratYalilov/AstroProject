# Изхар далёких букв (мутабаъидайн)

Четвёртый, последний вид отношения двух встретившихся букв — **далёкие (<span class="arab">متباعدان</span>)**.

## Определение

**Далёкие буквы** — это буквы из **разных, не близких** махраджей: один махрадж здесь, другой — там, **без всякой близости** между ними.

## Правило: всегда изхар

Если встречаются **две далёкие** буквы и **первая неподвижна** — **идгама нет**, делается **изхар** (ясное, раздельное произнесение). Это и есть «положение по умолчанию» для далёких букв.

Примеры (буквы из разных дальних махраджей): **<span class="arab">مَنْ خَلَقَ، أَنْعَمْتَ، يَجْعَلُونَ</span>** и т. п. — первая буква произносится **ясно**, без слияния со второй.

## Сводно по четырём видам

- **одинаковые (<span class="arab">مثلان</span>)** — идгам (обязателен);
- **однородные (<span class="arab">متجانسان</span>)** — идгам (в перечисленных случаях);
- **близкие (<span class="arab">متقاربان</span>)** — идгам в части случаев;
- **далёкие (<span class="arab">متباعدان</span>)** — **изхар** всегда.
