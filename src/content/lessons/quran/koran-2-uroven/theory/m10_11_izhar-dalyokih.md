# Изхар далёких букв (мутабаъидайн)

Четвёртый, последний вид отношения двух встретившихся букв — **далёкие (متباعدان)**.

## Определение

**Далёкие буквы** — это буквы из **разных, не близких** махраджей: один махрадж здесь, другой — там, **без всякой близости** между ними.

## Правило: всегда изхар

Если встречаются **две далёкие** буквы и **первая неподвижна** — **идгама нет**, делается **изхар** (ясное, раздельное произнесение). Это и есть «положение по умолчанию» для далёких букв.

Примеры (буквы из разных дальних махраджей): **مَنْ خَلَقَ، أَنْعَمْتَ، يَجْعَلُونَ** и т. п. — первая буква произносится **ясно**, без слияния со второй.

## Сводно по четырём видам

- **одинаковые (مثلان)** — идгам (обязателен);
- **однородные (متجانسان)** — идгам (в перечисленных случаях);
- **близкие (متقاربان)** — идгам в части случаев;
- **далёкие (متباعدان)** — **изхар** всегда.
