# Сочетание <span class="arab">قْ</span> + <span class="arab">ك</span> (слово <span class="arab">نَخْلُقكُّمْ</span>)

Имам аль-Джазари: **«<span class="arab">وَالْخُلْفُ بِنَخْلُقْكُّمْ وَقَعْ</span>»**.

## Слово <span class="arab">نَخْلُقكُّمْ</span>

В суре **аль-Мурсалят**: **<span class="arab">أَلَمْ نَخْلُقكُّمْ مِّن مَّاءٍ مَّهِينٍ</span>** — здесь встречаются **«<span class="arab">قَاف</span> (қаф)» неподвижная** и **«<span class="arab">كَاف</span> (кәф)»**. Они из близких махраджей: **<span class="arab">ق</span>** — глубже (задняя часть языка + мягкое нёбо), **<span class="arab">ك</span>** — чуть ближе ко рту.

## Расхождение (<span class="arab">الخلف</span>)

- **Большинство** чтецов читают здесь **полный идгам**: «каф» полностью сливается в «кяф» → произносится **удвоённая «кяф»**, без следа «каф».
- Двое больших имамов — **Макки ибн Абу Талиб аль-Кайси** и **Абу Бакр ибн Михран** — допускали **неполный идгам** (сохранить **исти‘ля** «каф», как итбак в **<span class="arab">أَحَطتُ</span>**).

(«Каф» сильнее «кяф», но **не настолько**, как «та» сильнее «<span class="arab">ت</span>» — ведь у «та» есть **итбак**. Поэтому здесь идгам уместен.)

## Чтение по Хафсу

Иснады **Хафса** (и по «Шатыбийе», и по «Тайибе») **не проходят** через Макки и Ибн Михрана. Поэтому по Хафсу читается **полный идгам**: **<span class="arab">نَخْلُقكُّمْ</span>** → удвоённая «кяф», без следа «каф».

В мусхафе это обозначено так: над «каф» **нет знака сукуна**, а на «кяф» — **шадда** (значит, первую произносим как вторую → удвоённая «кяф»). Хотя имам и упомянул «расхождение», для **нашего** чтения (Хафс) — **полный идгам**.
