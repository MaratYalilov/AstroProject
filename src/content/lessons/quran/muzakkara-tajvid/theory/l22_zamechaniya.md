# Важные замечания по чтению

## Замечание первое: слова, пишущиеся через сад, читаемые через син

- <span class="arab">يَبصُط</span> и <span class="arab">بَصطَة</span> — пишутся через сад, читаются через син.
- <span class="arab">المُصَيطِرُون</span> — пишется через сад, читается и через син, и через сад.
- <span class="arab">بِمُصَيطِرٍ</span> — пишется и читается через сад.

## Замечание второе: слово «дуъф» в суре «ар-Рум»

Допустимы оба варианта — фатха и дамма — в слове <span class="arab">ضَعف</span> / <span class="arab">ضُعف</span>:

<div class="arab">خَلَقَكُم مِن ضَعفٍ ثُمَّ جَعَلَ مِن بَعدِ ضَعفٍ قُوَّةً ثُمَّ جَعَلَ مِن بَعدِ قُوَّةٍ ضَعفًا</div>

## Замечание третье: варианты, имала и тасхиль

В слове <span class="arab">ءَاتَانِيَ اللَّهُ</span> («ан-Намль», 36) при остановке допустимы оба варианта — с йа и без йа; при слитном чтении — с открытой йа.

**Имала:** у Хафса имала есть только в слове <span class="arab">مَجرَيهَا</span> в суре «Худ» (аят 41). Имала алифа влечёт таркик ра.

**Тасхиль (смягчение хамзы):** Хафс смягчает хамзу аль-катъ только в слове <span class="arab">ءَاعجَمِيٌّ</span> в суре «Фуссылят» (аят 44) — вторая хамза произносится мягче.

## Замечание четвёртое: две хамзы васль подряд

<span class="arab">بِئسَ الاسمُ الفُسُوقُ</span> («аль-Худжурат», 11): при слитном чтении обе хамзы васль опускаются, лам получает кясру. При начале чтения слово начинают с хамзы васль артикля.
