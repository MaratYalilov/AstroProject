# Места артикуляции букв (махариджуль-хуруф)

Мест артикуляции семнадцать — по наиболее принятому мнению. Они распределяются по пяти органам: джауф (полость), халк (горло), лисан (язык), шафатан (губы), хайшум (носовая полость).

## 1. Джауф (полость)

Пространство внутри рта при раздвижении челюстей во время произнесения букв мадда. Одно место, из которого выходят три буквы мадда:

- <span class="arab">أَلِف</span> (әлиф) с сукуном после фатхи;
- <span class="arab">وَاو</span> (уау) с сукуном после даммы;
- <span class="arab">يَاء</span> (йә) с сукуном после кясры.

Они называются **буквами мадда**, или **джауфийскими**.

## 2. Халк (горло) — три места

- **Самая дальняя часть (акса-ль-халк):** хамза (<span class="arab">ء</span>) и <span class="arab">هَاء</span> (һә).
- **Середина (авсат-аль-халк):** <span class="arab">عَيْن</span> (٬әйн) и <span class="arab">حَاء</span> (хә).
- **Ближняя часть (адна-ль-халк):** <span class="arab">غَيْن</span> (ғайн) и <span class="arab">خَاء</span> (ҳа).

Все вместе — **горловые буквы (аль-хуруф аль-халкийя)**.

## 3. Лисан (язык) — десять мест

- **Корень языка с приподниманием + нёбо:** <span class="arab">قَاف</span> (қаф).
- **Корень языка с опусканием + нёбо:** <span class="arab">كَاف</span> (кәф). Каф и кяф — **увулярные (лахавийятан)**.
- **Середина языка + нёбо:** <span class="arab">جِيم</span> (дҗим), <span class="arab">شِين</span> (шин), <span class="arab">يَاء</span> немадийская. Называются **шаджарийскими**.
- **Край языка + верхние коренные зубы:** <span class="arab">ضَاد</span> (ḍад). С левой стороны — легче и чаще.
- **Края языка + верхние дёсны** (после места дада): <span class="arab">لاَم</span> (ләм).
- **Кончик языка + свод нёба над корнями верхних резцов:** <span class="arab">نُون</span> (нун).
- **Кончик языка + свод нёба, глубже места нуна:** <span class="arab">رَاء</span> (ра). Лам, ра и нун — **зальковые**.
- **Кончик языка + корни верхних резцов:** <span class="arab">دَال</span> (дәль), <span class="arab">تَاء</span> (тә), <span class="arab">طَاء</span> (Ṭа). Называются **натъийскими**.
- **Кончик языка + верхние и нижние резцы:** <span class="arab">سِين</span> (син), <span class="arab">صَاد</span> (ċад), <span class="arab">زَاي</span> (зәй). Называются **аслийскими**.
- **Спинка кончика языка + края верхних резцов:** <span class="arab">ثَاء</span> (ҫә), <span class="arab">ذَال</span> (ҙәль), <span class="arab">ظَاء</span> (ҙа). Называются **лясавийскими**.

## 4. Шафатан (губы) — два места

- **Внутренняя сторона нижней губы + края верхних резцов:** <span class="arab">فَاء</span> (фә).
- **Обе губы вместе:** <span class="arab">بَاء</span> (бә), <span class="arab">مِيم</span> (мим), <span class="arab">وَاو</span> немадийский. Ба и мим — при смыкании губ, уау — при их раскрытии. Называются **губными (шафавийскими)**.

## 5. Хайшум (носовая полость)

Одно место, из которого исходит **гунна** — постоянная характеристика, встроенная в природу мима и нуна в любом их состоянии.

## Замечания

**Как определить место артикуляции:** огласуй букву сукуном (или удвой) и добавь перед ней хамзу; там, где заканчивается звук, — там и место артикуляции. Например: <span class="arab">أَبْ</span>, <span class="arab">أَقْ</span>, <span class="arab">أَمْ</span>.

**Реальные и условные места:** все места реальные, кроме джауфа — он условный (нельзя точно указать место).

Букв в арабском алфавите двадцать восемь, а в науке таджвид — **двадцать девять**: хамза прибавляется к буквам алфавита.
