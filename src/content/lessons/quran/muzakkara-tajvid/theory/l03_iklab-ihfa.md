# Правила нун-сакина и танвина: икляб и ихфа

## Третье: Икляб (замена)

**Языковое значение:** изменение чего-либо относительно его первоначального состояния.

**Терминологическое значение:** превращение нун-сакина или танвина в скрытый <span class="arab">مِيم</span> (мим) с гунной перед буквой <span class="arab">بَاء</span> (бә). Буква икляба — только <span class="arab">بَاء</span>.

**Примеры:**

<div class="arab">مِنْ بَعْدِ ، الْأَنْبِيَاءَ ، عَلِيمٌ بِذَاتٍ</div>

## Четвёртое: Ихфа (скрытие)

**Языковое значение:** сокрытие.

**Терминологическое значение:** произнесение буквы в промежуточном состоянии между изхаром и идгамом с соблюдением гунны. Называется «подлинным ихфа» (аль-ихфа аль-хакики).

**Буквы ихфа:** пятнадцать, собраны в первых буквах слов двустишия:

<div class="arab">صِفْ ذَا ثَنَا كَمْ جَادَ شَخْصٌ قَدْ سَمَا ٭ دُمْ طَيِّبًا زِدْ فِي تُقًى ضَعْ ظَالِمَا</div>

<div class="arab">ص ، ذ ، ث ، ك ، ج ، ش ، ق ، س ، د ، ط ، ز ، ف ، ت ، ض ، ظ</div>

*Техника произношения ихфа:* частичное сближение места артикуляции буквы ихфа без давления на него — до завершения гунны.

**Примеры для каждой буквы** (в одном слове — в двух словах — с танвином):

| Буква | Примеры |
|-------|---------|
| <span class="arab">ص</span> | <span class="arab">مَنصُورَا — مِنْ صِيَامٍ — بِرِيحٍ صَرْصَرٍ</span> |
| <span class="arab">ذ</span> | <span class="arab">أَنْذِرْهُمْ — مَنْ ذَا الَّذِي — وَطَعَامًا ذَا</span> |
| <span class="arab">ث</span> | <span class="arab">مَنْثُورًا — مِنْ ثَمَرَةٍ — نُطْفَةٍ ثُمَّ</span> |
| <span class="arab">ك</span> | <span class="arab">أَنكَالًا — أَنْ كَانَ — أَجْرٍ كَرِيمٍ</span> |
| <span class="arab">ج</span> | <span class="arab">أَنجَاكُمْ — أَنْ جَاءَكُمْ — شَيْئًا جَنَّاتٍ</span> |
| <span class="arab">ش</span> | <span class="arab">مَنشُورًا — لِمَنْ شَاءَ — جَبَّارًا شَقِيًّا</span> |
| <span class="arab">ق</span> | <span class="arab">يَنقَلِبُونَ — أَنْ قَدْ — عَفُوًّا قَدِيرًا</span> |
| <span class="arab">س</span> | <span class="arab">الْإِنسَانُ — مِنْ سُلَالَةٍ — قِيلًا سَلَامًا</span> |
| <span class="arab">د</span> | <span class="arab">أَنْدَادًا — مِنْ دَابَّةٍ — قِنْوَانٌ دَانِيَةٌ</span> |
| <span class="arab">ط</span> | <span class="arab">يَنطِقُونَ — مِنْ طِينٍ — صَعِيدًا طَيِّبًا</span> |
| <span class="arab">ز</span> | <span class="arab">أَنزَلْنَاهُ — فَإِنْ زَلَلْتُمْ — يَوْمَئِذٍ زُرْقًا</span> |
| <span class="arab">ف</span> | <span class="arab">أَنفُسِكُمْ — وَإِنْ فَاتَكُمْ — أَزًّا فَلَا</span> |
| <span class="arab">ت</span> | <span class="arab">كُنتُمْ — مِنْ تَحْتِهَا — جَنَّاتٍ تَجْرِي</span> |
| <span class="arab">ض</span> | <span class="arab">مَنضُودٌ — مِنْ ضَعْفٍ — مُسْفِرَةٌ ضَاحِكَةٌ</span> |
| <span class="arab">ظ</span> | <span class="arab">يُنظَرُونَ — إِلَّا مَنْ ظَلَمَ — ظِلًّا ظَلِيلًا</span> |
