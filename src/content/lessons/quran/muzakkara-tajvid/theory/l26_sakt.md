# Сакт (краткая пауза без вдоха)

**Определение:** остановка без вдоха на длину двух харакáт с намерением продолжить чтение.

## Четыре места по единогласному мнению

1. Между <span class="arab">عِوَجًا</span> и <span class="arab">قَيِّمًا</span> — «Кахф», 1–2.
2. Между <span class="arab">مَرقَدِنَا</span> и <span class="arab">هَذَا</span> — «Йа Син», 52.
3. Между <span class="arab">مَن</span> и <span class="arab">رَاق</span> — «аль-Кыяма», 27.
4. Между <span class="arab">بَل</span> и <span class="arab">رَانَ</span> — «аль-Мутаффифин», 14.

## Два места, по которым есть разногласие

1. Между сурами «аль-Анфаль» и «ат-Тауба» — допустимы также соединение и полная остановка.
2. Между <span class="arab">مَالِيَه</span> и <span class="arab">هَلَكَ</span> — «аль-Хакка», 28–29 — допустимы также идгам и остановка.

> **Примечание:** <span class="arab">عِوَجًا</span> — конец аята, <span class="arab">مَرقَدِنَا</span> — конец слов неверующих, поэтому на обоих допустимы и остановка, и сакт. А на <span class="arab">مَن</span> и <span class="arab">بَل</span> — только сакт, остановка недопустима.
