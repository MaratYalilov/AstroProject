# Встроенный CSS для всего словаря - 19 октября 2026 года

## Основание

После нарезки шрифтов и раннего запуска QCF пользователь получил 95 баллов на «Азане». Для «Азаб аль-кабр» отдельно проверена загрузка CSS: локальная медиана FCP 1,468 -> 0,724 с, LCP 1,764 -> 1,036 с. После публикации пользователь прислал [PageSpeed 83emkta3o8](https://pagespeed.web.dev/analysis/https-hutba-org-glossary-azab-al-kabr/83emkta3o8?form_factor=mobile): 100 баллов, FCP 0,912 с, LCP 1,126 с, TBT 0 мс, CLS 0,003.

По просьбе владельца механизм распространён на весь словарь. Этот результат одной статьи не гарантирует 100 баллов для каждой другой статьи.

## Изменение

- `src/middleware.ts` обрабатывает `/glossary` и пути внутри `/glossary/`, включая завершающий `/`. Проверяются статус 200 и тип `text/html`; страницы других разделов и `/api/glossary` не меняются.
- Список отдельных разрешённых статей удалён. Для каждой исходной страницы `inlineGlossaryCriticalCss` автоматически выбирает подходящие правила из общего CSS по серверному HTML.
- Общий маркер - `data-critical-css="glossary"` / `data-deferred-css="glossary"`.
- Полный CSS без повторных `@font-face` загружается отложенно и используется для меню, переходов и другого динамического содержимого. Без JavaScript его подключает `noscript`.
- Сохраняются обе темы, порядок правил, media/supports, псевдоклассы, SVG и объявления шрифтов. При неоднозначной структуре стилей или отсутствии сокращения сохраняется исходное подключение.
- Общий адрес `/styles/azan/<hash>.css` оставлен прежним; переименование адреса для расширения области не требуется.

Шрифты, данные Корана, аудио, тексты статей и загрузка других разделов не менялись.

## Проверки без сборки

На работающем локальном сервере проверены все **369 статей и страница списка - 370 HTML-ответов**. Во всех случаях есть встроенный набор, отложенный общий файл и `noscript`. Размер встроенного CSS - от 21 999 до 26 857 байт до сжатия. CSS-адрес общий, возвращает 200 и `text/css`, его хеш совпадает с содержимым; повторных `@font-face` нет.

Для `/glossary`, «Азана», «Азаб аль-кабр», «Аврата», «А'рафа», «Аль-Кахтани» и «Барзаха» сравнивались исходный полный CSS и встроенный набор. Внешний CSS и внешние скрипты в контрольном варианте блокировались, чтобы они не могли скрыть недостающие начальные правила. **28 сравнений**: семь страниц, две темы, ширины 412 и 1350. Геометрия основного блока и первые экраны совпали попиксельно.

С обычными скриптами проверены поиск, переход Аврат -> список -> Азан, возврат и переход вперёд в истории, открытие и закрытие мобильного меню. Ошибок JavaScript нет. Статьи и список читаются без JavaScript.

Проверено отсутствие нового маркера на главной, странице «О проекте» и JSON API словаря. Адреса `/glossary/` и `/glossary/avrat/` обрабатываются. `scripts/test-critical-css.mjs`, точечная проверка TypeScript и `git diff --check` прошли. Сборка не запускалась.
