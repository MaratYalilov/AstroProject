# Разбивка острова урока

План выноса статьи урока из React-острова `LessonPage`. Цель - снизить TBT 450-500 мс, не меняя вид и поведение страницы.

## Что сейчас

`src/pages/lesson.astro` передаёт в `<LessonPage client:load>` объект `currentLesson`, внутри которого лежит **весь HTML статьи** (до 370 КБ). Остров получает его как prop, и Astro сериализует строку в JSON острова.

`LessonPage`:

- делит HTML по маркерам `<div class="dic-flashcard-marker" data-lesson data-words>` на куски;
- куски текста выводит через `dangerouslySetInnerHTML`;
- между ними рендерит `DictionaryFlashcard` (интерактивные карточки);
- владеет медиа, тулбаром, программой курса, прогрессом, поиском, завершением урока, последним уроком и позиционированием активного пункта.

Важно: React не гидратирует внутренности `dangerouslySetInnerHTML`, поэтому «тысячи узлов» сами по себе не гидратируются. Основная цена - **полный HTML в prop острова**, его разбор, куски статьи как React-узлы и общий остров с медиа и программой.

## Целевая схема

Серверный Astro отвечает за каркас, заголовок, медиа и статью. Островами остаются только управления:

| Часть | Где | Гидрация |
| --- | --- | --- |
| Каркас, h1, хлебные крошки | Astro | нет |
| Видео/аудио | Astro, нативный `<video>`/`<audio>` | нет |
| Статья и текст | Astro, `set:html` | нет |
| Карточки словаря | `DictionaryFlashcard` | `client:visible` |
| Программа курса, прогресс, поиск, активный пункт | `CourseProgram` | `client:idle` |
| Тулбар: назад/вперёд, видео/аудио, аудио, программа, завершение | `LessonToolbar` | `client:idle` |
| Подсказки терминов | `GlossaryOverlay` в `Base` | уже `client:idle` |
| Кнопка «Наверх» | `ScrollToTop` | уже есть |

## Этапы

### Этап 1. Статья и карточки на сервере

1. Вынести разбор HTML в `src/lib/lessonContent.ts`:
   - `splitLessonHtml(html)` возвращает массив `{ kind: 'html', html }` и `{ kind: 'dic', lessonNumber, words }`;
   - `hasContentH1(html)`;
   - нормализация `\r\n`.
2. Добавить `src/components/lesson/LessonArticle.astro`:
   - `<article class="lesson-reading ...">`;
   - sr-only `h1`, если в статье нет своего;
   - `TeacherCredit`;
   - текст через `<div class="lesson-text" set:html={segment.html} />`;
   - карточки через `<DictionaryFlashcard client:visible ... />`.
3. В `lesson.astro` рендерить статью в левой колонке, а не внутри `LessonPage`.
4. Убрать `html` из props острова, оставив только метаданные урока.

Проверка: текст совпадает, карточки переворачиваются, h1 один, ссылки-термины и QCF работают, мобильная и десктопная вёрстка не меняется, HTML острова больше не содержит статью.

### Этап 2. Медиа

1. Вынести `<video>`/`<audio>` в Astro. Это нативные элементы, React им не нужен.
2. Оставить маленький остров `LessonMediaControls`:
   - переключение видео/аудио, если есть оба;
   - кнопка озвучки, скачивание;
   - стрелки назад/вперёд поверх медиа на мобильном.
3. Атрибут `data-quran-audio-ready` выставлять сразу в разметке, а не после гидрации.

### Этап 3. Программа и тулбар

1. `CourseProgram` получает компактный список уроков, текущий slug и прогресс:
   - поиск, список, прогресс, подсветка завершённых, прокрутка к активному.
2. `LessonToolbar`:
   - назад/вперёд, видео/аудио, аудио, программа, «Отметить завершённым».
3. Завершение урока и последний урок остаются в островах, работа с `localStorage` не меняется.

### Этап 4. Удаление старого

1. Удалить `LessonPage.tsx` или оставить только неиспользуемые части, если что-то ещё импортируется.
2. Проверить `blog.tsx` (учебник) и интерактивные курсы - их не трогаем.
3. Проверить 404 для неизвестного slug, урок без медиа, урок с аудио, урок с видео и аудио.

## Что проверять после каждого этапа

- один `h1`, нет дублей статьи;
- статья и карточки совпадают с текущими;
- ссылки-термины, QCF, аудиокнопки, видео;
- прогресс и «Завершён» сохраняются после перезагрузки;
- переход на последний урок и очистка памяти на 404;
- мобильный и десктопный вид;
- размер HTML, размер props острова и TBT после выкладки.

## Риски

- **Карточки словаря**: маркеры находятся в HTML; серверный разбор должен совпадать с текущим, иначе карточки пропадут.
- **Аудиокнопки в статье**: глобальный скрипт ждёт `data-quran-audio-ready`; атрибут нужно выставить до его запуска.
- **Термины**: `useGlossaryTermTarget` завязан на slug урока; при выносе передать slug в разметку или в маленький скрипт.
- **Медиа**: переключение видео/аудио требует состояния; не тащить в него статью.
- **Программа курса**: список уроков должен остаться компактным, без HTML статьи.
- **Учебник и интерактивные курсы** идут через другие компоненты, их менять не нужно.

## Порядок работ

Начинать с этапа 1. Он даёт основной выигрыш: из props острова уходит вся статья, а сервер отдаёт её сразу. Этапы 2-3 уменьшают остров дальше, но их можно делать после замера.
