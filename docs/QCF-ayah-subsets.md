# Нарезка QCF V2 по аятам

Скрипт: [scripts/trial-qcf-ayah-subsets.py](../scripts/trial-qcf-ayah-subsets.py). Несмотря на прежнее имя `trial`, это самостоятельный инструмент для всех 604 страниц QCF V2 и 6236 аятов. Он не запускает Astro и не меняет подключение шрифтов на сайте.

Требуется Python 3.10 или новее. Из корня проекта установить зависимости:

```powershell
python -m pip install -r scripts/requirements-qcf-subsets.txt
```

## Полная нарезка

```powershell
python scripts/trial-qcf-ayah-subsets.py
```

По умолчанию:

- Исходники: `public/fonts/mushaf-v2-woff2/p1.woff2` - `p604.woff2`.
- Данные аятов: `src/data/quran-qcf-v2.json`.
- Результат: `public/fonts/qcf-ayah-v2/`, например `16-36.woff2`, `6-151.woff2`.
- Реестр: `public/fonts/qcf-ayah-v2/manifest.json` с размерами, SHA-256, исходной страницей и отметкой проверки.
- Одновременно обрабатываются до четырёх страниц. Число процессов можно задать через `--workers 2`.

Исходники не перезаписываются. Скрипт сначала проверяет все выбранные исходные файлы и наличие нужных символов, затем создаёт результат. Каждый WOFF2 сначала записывается во временный файл; только после проверки контуров, метрик и кодов он заменяет готовый файл. Сохраняются хинтинг, возможности OpenType и исходные округлённые границы знаков.

Полная нарезка может занять продолжительное время. Скрипт выводит прогресс и сохраняет реестр после каждых пяти обработанных страниц и при обычном завершении. При аварийной остановке готовые, но ещё не записанные в реестр файлы будут пересозданы при продолжении.

## Продолжение и повторная проверка

```powershell
python scripts/trial-qcf-ayah-subsets.py --resume
```

Готовые файлы повторно используются только при совпадении контрольных сумм исходника, кодов аята и самого результата. Повреждённый или недостающий файл создаётся заново. При изменении версии FontTools или карты аятов нужна новая папка результата. Непустая посторонняя папка без подходящего реестра не перезаписывается.

Дата изменения внутри выходного шрифта сохраняется из исходника: повторная генерация при одинаковых исходниках, зависимостях и параметрах воспроизводима. Во время запуска не следует менять исходные шрифты или одновременно запускать второй процесс для той же выходной папки.

Только проверить исходники всех страниц, ничего не создавать:

```powershell
python scripts/trial-qcf-ayah-subsets.py --check
```

## Выбор страниц, аятов и папок

```powershell
python scripts/trial-qcf-ayah-subsets.py --pages 1,148,264-266 --output-dir D:/QCF/selected
python scripts/trial-qcf-ayah-subsets.py --ayahs 16:36,6:151 --output-dir D:/QCF/citations
python scripts/trial-qcf-ayah-subsets.py --source-dir D:/QCF/pages --output-dir D:/QCF/ayahs --resume
```

Если указаны и `--pages`, и `--ayahs`, выбирается их пересечение. Исходная и выходная папки должны быть разными и не находиться одна внутри другой. Дополнительные параметры: `--map` для пути к карте QCF и `--tools-dir` для отдельной папки с зависимостями. Относительные пути в параметрах считаются от текущей папки терминала; пути по умолчанию считаются от расположения проекта.

Скрипт рассчитан на монохромный QCF V2. Цветной QCF V4 он явно отклоняет: цветовые таблицы требуют отдельной проверки. Нарезанные файлы не подключаются к урокам автоматически. Данные в `public` игнорируются Git и при последующем внедрении переносятся отдельно.

При подключении каждому аяту нужно отдельное имя семейства, например `QCF-6-151`. Это позволяет одновременно использовать несколько нарезанных файлов одной страницы мусхафа. Имя задаётся загрузчиком `FontFace` или правилом `@font-face`; текущий скрипт только готовит файлы и реестр.

## Результаты предварительных измерений

Для шести цитат урока 40 QCF-файлы уменьшились с 946 до 214 КиБ, на 77,4%. При нарезке всей страницы мусхафа суммарный размер может увеличиться, поэтому общий файл страницы тоже остаётся полезен. [Краткий отчёт](HUTBA-qcf-ayah-subset-trial-2026-10-17.md).

Проверки командной строки на небольших временных шрифтах:

```powershell
python scripts/test_qcf_ayah_subsets.py
```

Проверяются создание файлов, продолжение без повторной записи, восстановление повреждения, отсутствующий знак, выбор аятов и защита посторонних файлов. Тесту доступны те же зависимости, параметр `--tools-dir` также поддерживается.

17.10.2026 проверены входные данные всех 604 страниц и 6236 аятов. Реально нарезаны 48 аятов выбранных страниц, затем отдельно по одному аяту с каждой из 604 страниц; контуры и метрики совпали. Полная генерация всех 6236 файлов в этой проверке не выполнялась. Проверочные файлы не включены в репозиторий.
