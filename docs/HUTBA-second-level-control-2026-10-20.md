## Кандидат на изменение после исходного контроля

Крупнейший JS-ресурс - `InteractiveLessonPage.oed3ac8g.js`: 303 666 байт передачи с заголовками, около 297 КиБ. В мобильном проходе запрос закончился примерно на 5,53 с, хотя чтение началось раньше.

В `src/components/course/MatnBlock.tsx` сохранился статический импорт всего `sharh.json`: 109 комментариев, 849 695 байт исходного JSON, 189 058 байт при отдельном gzip. Последнее значение характеризует исходный файл, а не точный вклад в опубликованный бандл.

Полный Markdown используется для проверки наличия комментария и поиска ссылки на термин. Отображение уже получает HTML через серверный API. Следующее изменение - оставить на клиенте компактные признаки наличия шарха и связи терминов с бейтами, а тексты держать на сервере. Нужно сохранить автоматическое раскрытие шарха по ссылке из словаря, обычное раскрытие, повтор запроса после ошибки и отмену запроса при смене урока. Реальный выигрыш измерять после изменения; заранее обещать уменьшение LCP нельзя.

Исходный код сайта при этом контроле не менялся. Сборка не запускалась. Снимки, результаты и проверочные скрипты находятся в игнорируемой `.astro/second-level-*`, `.astro/profile-second-level.cjs` и `.astro/check-second-level-controls.cjs`.

## Выполненное изменение: компактный индекс шархов

- `src/lib/interactive/prepareMatnComments.ts` на сервере получает из актуального `sharh.json` наличие комментариев и ссылки на термины. Отдельного сгенерированного файла для ручного обновления нет.
- `loadAllInteractiveLessons` добавляет каждому Matn-блоку только индекс его диапазона. Подготовка работает как для бандла, так и для отдельных JSON уроков, включая прямой вход через `/lesson` и переключение курса. Общие исходные объекты уроков не изменяются.
- `src/lib/interactive/types.ts` и `renderBlock.tsx` передают индекс в `MatnBlock`.
- Из `src/components/course/MatnBlock.tsx` удалён импорт полного `sharh.json`. Пустой список терминов означает существующий шарх без ссылок и сохраняет кнопку раскрытия. HTML комментария приходит через прежний серверный API после раскрытия.
- `src/utils/glossaryTarget.ts` выделяет список ссылок теми же правилами, что и прежняя проверка одного термина. Сохранены HTML/Markdown ссылки, декодирование адресов и отсечение внешних доменов.

Полные исходные комментарии: 849 695 байт JSON, 189 058 байт при отдельном gzip. Индекс всех 109 шархов: 1207 байт JSON. На локальной странице курса из 280 уроков сериализованные записи всех Matn-блоков занимают 2207 байт, 553 байта при отдельном gzip, до экранирования атрибута HTML. Эти значения не равны изменению размера готового бандла: сборка не запускалась.

В локальном браузере до изменения запрашивался `sharh.json?import`, после изменения такого запроса нет. Точный выигрыш итоговой передачи и времени готовности управления проверяется после публикации новой версии. Сравнивать замедленный dev-сервер с опубликованной production-версией как измерение ускорения нельзя; пробный замедленный dev-проход не завершил гидратацию за лимит и не использован как результат.
