# Начальные стили курса второго уровня - 20 октября 2026 года

## Решение

Для `/quran/koran-2-uroven` включён тот же механизм встроенного CSS, который уже используется в словаре. Работает для всех значений `?lesson=`, включая URL без параметра и с завершающим `/`. Остальные курсы используют прежнее подключение CSS.

- `src/middleware.ts` выбирает область `interactive-course` только для этого курса, сохраняя область `glossary` для словаря. Обрабатываются только HTML-ответы 200.
- В HTML встраиваются подходящие правила из текущего общего CSS. Маркеры - `data-critical-css="interactive-course"` и `data-deferred-css="interactive-course"`.
- Общий файл под прежним хешированным адресом `/styles/azan/<hash>.css` подключается отложенно. Без JavaScript его подключает `noscript`. Повторных объявлений `@font-face` в отложенном файле нет.
- `src/components/course/CourseSidebar.tsx` сразу раскрывает модуль текущего урока в серверном HTML. До изменения он раскрывался эффектом после гидратации; правила его дочерних кнопок отсутствовали в исходной разметке. Теперь эти правила попадают во встроенный набор и меню доступно без ожидания React. Эффект продолжает переключать модуль при смене урока.

Основной набор экономит около 20 КБ, но требует второго файла для полного покрытия. Такая схема не подключалась. Исходные Amiri, набор символов и цепочка `.arab` сохранены. Данные пробы - в игнорируемой `.astro/amiri-trial/result.json`. Правила сохранения OpenType-соединений при нарезке: [FontTools subset](https://fonttools.readthedocs.io/en/latest/subset/index.html).

## Обновление на домене во время работы

Во время публикации 20 октября HTML кратковременно ссылался на `Base.cBbqjeno.css` и `CourseLayout.B4wm5lZS.js`, которые отвечали 404. Владелец подтвердил обновление. Затем HTML получил новые адреса, все девять начальных ресурсов вернули 200. Замеры не выполнялись на странице с недоступными ресурсами.

Для проверки после следующих публикаций добавлен `scripts/check-page-assets.mjs`. Он читает текущий HTML и проверяет CSS, начальные скрипты, входные модули островов и изображения с адресами `/_astro/`. Это не полный обход зависимостей импортированного JS и не проверка медиа. Код ответа 200 одной HTML-страницы не заменяет эту проверку.
