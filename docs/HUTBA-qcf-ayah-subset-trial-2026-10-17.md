# Итоги проверки нарезки QCF V2

Дата: 17 октября 2026 года. Результаты сохранены как основание дальнейшей работы. Временные HTML, изображения, WOFF2, сырые измерения и локальное подключение эксперимента удалены перед подготовкой коммита по просьбе владельца. Сборка и публикация не выполнялись.

## Размеры шрифтов

| Случай | До | После нарезки по аятам | Изменение |
| --- | ---: | ---: | ---: |
| Шесть цитат урока 40 с шести страниц мусхафа | 946 КиБ | 214 КиБ | На 77,4% меньше |
| Все пять аятов страницы 148 | 122 КиБ | 129 КиБ | На 5,8% больше |
| Все двадцать аятов страницы 264 | 180 КиБ | 222 КиБ | На 23,6% больше |

В проверке 30 уникальных шрифтов использован FontTools 4.67.0 с сохранением хинтинга и возможностей OpenType. Контуры и горизонтальные метрики совпали с исходниками. В Edge 155.0.4283.45 все 90 сравнений при размерах 24, 40 и 64 пикселя совпали по ширине и пикселям. Это проверка монохромного V2; цветной V4 не проверялся.

## Локальное подключение урока 40 и замер всей страницы

Проводилось временное подключение только урока 40 в режиме Astro dev. Три холодных запуска каждого варианта, экран 412 × 823, сеть 200 КиБ/с, задержка 150 мс, CPU ×4, кеш отключён, одинаковое gzip-сжатие текстовых ресурсов. Ниже медианы:

| Показатель | Исходные шрифты | По аятам |
| --- | ---: | ---: |
| Весь трафик | 3,86 МиБ | 3,14 МиБ |
| Готовность QCF-оформления аятов | 10,47 с | 4,89 с |
| FCP | 0,81 с | 0,77 с |
| LCP | 2,76 с | 2,76 с |
| Событие `load` | 11,83 с | 11,14 с |
| CLS | 0 | 0 |

Общий трафик уменьшился примерно на 18,5%, QCF готов примерно на 53% раньше. Ускорение первого экрана и рост PageSpeed не подтверждены: текст уже доступен до готовности QCF, а LCP соответствует видеопревью. Событие `load` не означает завершения всех последующих запросов приложения. Абсолютные числа разработки нельзя приравнивать к рабочему сайту.

Проверялись два размера экрана, одинаковый текст и размеры блоков, отсутствие ошибок React, общий запрос для адаптивных копий, Unicode при отключённом JavaScript и при ошибке шрифта. Аудиовызов проверен с перехватом `audio.play()`, фактическое звучание не проверялось.

## Состояние после очистки

Сайт снова использует исходные файлы страниц без экспериментального переключателя. Сохранён и обобщён [скрипт нарезки](../scripts/trial-qcf-ayah-subsets.py): теперь он выбирает все 604 страницы по умолчанию, поддерживает папки, отдельные страницы и аяты, реестр проверок и продолжение запуска. HTML сравнения он больше не создаёт.

[Инструкция запуска](QCF-ayah-subsets.md). Проверка исходников охватила 604 файла и 6236 аятов. Дополнительно создано 48 файлов для страниц 1, 48, 148, 264 и 604 с проверкой контуров и метрик. Затем успешно нарезано по одному аяту с каждой из всех 604 страниц: 604 результата прошли проверку. Проверены повторное использование готового результата, восстановление повреждённого файла и отказ от перезаписи посторонней папки; пять тестов командной строки прошли. Проверочные файлы удалены после завершения. Полная нарезка всех 6236 выходных файлов в рамках этой подготовки не запускалась.

Для отдельных цитат нарезка полезна; для целой страницы общий шрифт может быть выгоднее. Внедрение выбора шрифтов, проверка остальных браузеров и поддержка V4 остаются отдельными задачами.
