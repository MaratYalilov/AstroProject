# Связи словаря и уроков

Основная версия скрипта хранится в репозитории: `scripts/glossary_linker.py`.
Требования: Python 3.9+ и PyYAML (`pip install PyYAML`).

Из корня проекта:

```powershell
python scripts/glossary_linker.py --dry-run
python scripts/glossary_linker.py --write --report .astro/glossary-linker-report.json
```

При запуске копии из другой папки можно указать проект явно:

```powershell
python glossary_linker.py --project-root "D:\Yandex.Disk\AstroProject" --write
```

Без `--write` скрипт показывает результат, но не изменяет контент. Отчёт записывается только при указании `--report`.

Обрабатываются обычные уроки Markdown, отдельные интерактивные JSON и `lessons.bundle.json`. Для интерактивных уроков учитываются подключённые файлы теории и комментарии `sharh.json` к нужным бейтам матна. В блоках произношения ссылки добавляются в описание, пункты, шаги и примечания, которые компоненты уже выводят как HTML. Поля, выводимые как обычный текст, SEO-описания, заголовки, арабский текст и пути к медиа не изменяются.

Скрипт использует названия терминов, варианты написания через запятую и `aliases`. Формы слов не угадываются. Список исключений `EXCLUDED_TERMS` сохранён. Если одно написание относится к нескольким статьям словаря, новая ссылка для него не добавляется; неоднозначности попадают в отчёт.

Для известных совпадений разных значений добавлена осторожная проверка контекста: «айн» связывается со статьёй о сглазе только при явном упоминании этого значения рядом. Имена «Халиль ибн ...», «Ибн Хасан» и части имён «ад-Дин» не связываются с определениями терминов. Это не заменяет редакторскую проверку новых ссылок.

Готовые ссылки сохраняются и учитываются в `used_in`. Новая ссылка на термин добавляется только при отсутствии такой ссылки в материалах урока. Общие файлы теории и комментариев учитывают все уроки, которые их используют. Код, диаграммы, ссылки, изображения, атрибуты HTML и заголовки защищены от замены.

`used_in` теперь содержит адреса уроков вместо имён файлов. Это устраняет совпадения одинаковых имён в разных курсах. Поле `related` собирается по совместному использованию терминов в уроках. Остальные поля и текст статьи словаря сохраняются. На страницах словаря блок «Уроки по теме» показывает только адреса, которые подтверждены каталогом уроков сайта.

После добавления или изменения материалов снова запустите скрипт с `--write`, отправьте изменения через GitHub и пересоберите сайт. Повторный запуск без изменений контента ничего не переписывает.

Проверки:

```powershell
python -m unittest discover -s scripts -p test_glossary_linker.py
```
