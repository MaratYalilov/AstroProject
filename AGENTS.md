# Инструкции проекта

## Проверка изменений

- Не запускать сборку проекта при внесении изменений или для их проверки. Это постоянное требование владельца проекта.
- Запрет распространяется на `npm run build`, `astro build`, вызов сборки через API Astro и сборку с временной конфигурацией, в том числе без копирования медиа.
- Запускать сборку только по явной просьбе пользователя в текущей задаче. Не предлагать её как обязательный шаг согласования обычных правок.
- Проверять изменения через локальный сервер, просмотр кода и подходящие точечные проверки без полной сборки проекта.

## Оформление текста

- В ответах пользователю, текстах сайта и документации проекта всегда использовать обычный дефис `-` вместо длинного и среднего тире (U+2014 и U+2013). При редактировании текста заменять такие тире в изменяемом материале на `-`.
